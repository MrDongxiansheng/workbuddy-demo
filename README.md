# workbuddy-demo

这是通过 **WorkBuddy 本地 GitHub MCP** 自动创建的演示仓库。

## 说明
- 由 WorkBuddy Agent 使用官方 `github-mcp-server`（Go 版）调用 GitHub API 创建。
- 鉴权方式：Personal Access Token（PAT），直连 `api.github.com`。
- 绕开了 WorkBuddy 云端 OAuth 那个会 500 的链接按钮。

## 我能用这个 MCP 做什么
- 创建 / 删除仓库
- 读写文件、提交代码
- 开 Pull Request、管 Issue
- 搜索仓库、代码、PR

> 仓库由 AI 助手代建，用于验证 GitHub 连接链路通畅。
